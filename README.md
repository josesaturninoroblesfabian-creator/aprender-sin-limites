# Aprende sin Límites

Prototipo para Godot 4, pensado para Windows y para funcionar sin internet.

## Abrir el proyecto

1. Abre Godot 4 y selecciona **Importar**.
2. Elige el archivo `project.godot` de esta carpeta.
3. Abre el proyecto y pulsa **F6** para ejecutar la escena.

## Incluye

- Portada con el fondo andino y botones interactivos.
- Saludo inicial con los MP3 locales de la niña y el niño, en ese orden.
- Personaje 3D inicial de la niña, construido con figuras 3D y vestido con colores andinos.
- En **Personaje 3D**, los botones permiten escuchar el saludo, caminar y volver al menú.
- Mientras suena el audio, la boca del modelo alterna entre cerrada y abierta.
- Lección de Lenguaje con paisaje andino limpio, cóndor guía, teclado del abecedario, progreso y navegación por diez ejemplos ilustrados para cada letra.
- Reproducción de palabras mediante la voz en español disponible en Windows.

Esta demo 3D es una primera versión sencilla para probar el modelo y los movimientos; se puede pulir el aspecto y añadir más animaciones en los siguientes pasos.
